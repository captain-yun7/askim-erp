2. `style(ui)` 버튼·입력 100px 필, 높이 36/44, 배지 `info`/`success` 변형, 카드 헤어라인 16px, 테이블 헤더 캡션(11px, +0.04em)

4. `style(dashboard)` / `style(deals)` 틴트 요약 카드, 블러시 알림, 상품구분 info 배지, 입금/결산 상태 닷

6. `fix(auth)` `/brand/*` 미들웨어 예외

## 규칙 요약 (앞으로 지킬 것)
- 인터랙션 요소는 전부 `rounded-full`; weight 500 이하
- 강조는 Ink(`primary`) 1색. Coral/Blush는 미입금·경고·삭제에만
- 요약 지표는 `bg-muted` 8px 틴트 카드, 목록/폼은 `border` 16px 카드
