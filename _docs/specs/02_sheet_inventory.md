## 3. 외화매출매입

- **역할**: 외화 거래 (USD/CNY, 알리페이 등)
- **실제 데이터**: **12건** (시트는 1469행이지만 형식만)
- **컬럼**: 원화와 동일 (총 42컬럼)
- **차이점**:
  - col4(귀속연도)·col5(귀속월) 대부분 비어있음 (외화 거래 운영방식 다름)
  - 매출수단 = 알리페이(9), 세금계산서(1)
  - 거래코드 prefix = **FJ** (김해준)
  - 매출금이 KRW 단위로 들어가 있지만 실제 결제는 외화

→ ERP에서는 **원화/외화 통합 한 테이블**, currency 컬럼으로 구분 권장

## 4. IP&협찬건

- **역할**: IP/협찬 특수 거래
- **실제 데이터**: 37건
- **헤더 위치**: R5
- **컬럼**: 원화매출매입과 거의 동일 (~25개)
- **특수 규칙**: *"총 수익의 20%를 나린님에게 쉐어"*
- 카테고리는 거의 `기타/자사` (인스타 폴씨 바이럴 광고 등)
- 담당자: 박지운, 이유정 위주

→ ERP에서는 **원화매출매입에 통합**하고 카테고리=IP/협찬으로 구분
→ "20% 나린 쉐어"는 **CommissionRule에 special_share 룰**로 추가
