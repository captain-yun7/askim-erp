# 주 목적
- 엑셀 파일을 ERP로 변환해서 각 유저가 자기 영역을 CRUD 할수 있도록

[외부 서비스]
- 경리나라 (카드/은행 이체 내역) -> 매입 
 * 매출 : 
- 더존 (실제 회계 관련 연관성은 부족)


[주요 기능]
영업 기준 
- 영업 매출/매입/손익 관리 (영업사원)
 - 카테고리, 매출, 매입 컬럼 등 입력
 * 참고 : 원화매출매입 탭  

- 등록/조회 폼 : 설문폼, 엑셀형 2가지
- 필수값, 선택값
- 자동채워넣기 (판관비 부분...) 

회계 기준
- 매출/매입/손익 -> 총 매출, 영업이익 등 파악 ( * 참조: 월별 수금 결산, 매출장표, 26년 plan)
- 목표 대비 현황 파악 (카테고리) (* 참조: 26년 plan)
- 현금흐름 파악 (월별 수금, 결산)
- 사무실에 사용한 비용 정리 (* 참조 : 판관비 외 탭 ->(ref) 매출장표 탭 )
- 거래처 별 매입/매출 관리 
  - 거래처 코드 부여해서 중복 방지
- 월별, 상품별, 팀별, 거래처별 매출 통계 (한번에 파악할 수 있게)
- 국내/중국/미국 법인별 독립 분리. (혹은 통합 관리할지는 추후 결정)

[현황]
- 현재는 팀원들이 매주 수정사항을 각기 다른 엑셀로 관리자에게 전달하고 관리자가 최종 수정
- 구글 스프레드 시트 -> 성능, 보안 등 요소 때문에 고려 x

[권한]
- 관리자, 팀장, 각 팀원(일반 유저)
- 관리자 : 모든 권한
- 팀장 : 관리자가 지정한 권한
- 팀원 : 관리자가 지정한 권한이지만 기본적으로 자기꺼만 관리
