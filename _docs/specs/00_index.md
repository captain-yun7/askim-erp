## 핵심 발견

### 사업 모델
- 옥외/매체 광고 대행사 (성수동 외벽 + 한강버스 + 해외매체 + 중국사업 중심)
- 매체사로부터 매입 → 광고주에게 매출 → 마진/수수료가 수익원
- 대행 거래(73%) vs 직거래(24%) 혼재
- 2026 매출 목표: 136억원 (5/12 달성률 30%)

### 데이터 규모
- 거래: 원화 563건 + 외화 12건 + IP/협찬 37건 (2023~2027)
- 거래처 마스터: 288건 (사업자번호 61% 누락)
- 판관비: 2,027건 / 9.5억원 (2025~2026)

### 회계 이중 관점
- **귀속월 기준** (발생주의) — 광고집행월
- **통장 기준** (현금주의) — 실제 입출금일
- 두 관점을 동시에 제공해야 함

### 특수 케이스
- **분할 거래** (156개 그룹, -1/-2/... suffix)
- **상계처리** (24건, 매출-매입 net 정산)
- **보증금/환급** (편측 거래)
- **페이백/비공식수수료** (전홍 5% 등)
- **인센티브 요율 변경** (2025.04.01)
- **나린 20% 쉐어** (IP/협찬 거래)

### ERP가 자동화할 것 (엑셀 7개 시트 → 자동 집계)
- 월별 수금결산, 월별손익, 월별매출&매입, 상위거래처, 매출장표, 십일조, 26년 plan 달성률

## 미해결 질문 (확정 후 모델 설계)

1. 분할 거래(-N) 의미: 매출 분할? 매입 분할? 매체 분할?
2. 귀속월 정의: 광고 시작월 / 종료월 / 다른 기준?
3. 매출수단에 추가 항목 있나? (계좌이체 등)
4. 매입건 카테고리 — 별도 모듈?
5. 외화 환율 적용 기준?
6. 부가세 신고 체크 — 사용할 건지?
7. 인센티브 1/N의 N — 동적 인원수?
8. 거래코드 채번 기준일: 광고시작일 vs 계약일 vs 등록일?
