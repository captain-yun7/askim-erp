# MVP 화면 와이어프레임

> 거래 입력 폼은 **좌(매출) / 우(매입) 2단 레이아웃** 확정.
> ASCII 와이어 + UX 디테일 + 우선순위.

---

## 1. 화면 맵

```
🔐 인증
  └─ 로그인

📊 메인 (P1)
  └─ 대시보드 — 월별 P&L 카드, 미입금/미결산 알림, 최근 거래

⭐ 거래 (P0 — MVP 핵심)
  ├─ 거래 목록 — 검색·필터, 정렬, CSV export
  ├─ 거래 입력/수정 — 좌(매출)/우(매입) 2단
  └─ 거래 상세 (조회 전용 옵션)

👥 거래처 (P0)
  ├─ 거래처 목록 — 검색, 역할별 필터
  └─ 거래처 입력/수정

💸 판관비 (P1)
  ├─ 판관비 목록
  └─ 판관비 입력 — 빠른 입력 폼

📈 리포트 (P1~P2)
  ├─ 매출장표 — 통장/귀속월 토글
  ├─ 월별 손익
  ├─ TOP 거래처
  └─ 십일조

⚙️ 관리 (P2, admin only)
  ├─ 사용자 관리
  ├─ Lookup 마스터 (카테고리/요율/계정 등)
  └─ 마이그레이션 리뷰 큐
```

### 2.2 UX 디테일

#### 자동완성 (거래처 검색)
- 글자 입력시 마스터에서 fuzzy match (한글 초성 검색 지원)
- 검색 결과 옆에 사업자번호·역할 태그 표시
- **거래처가 마스터에 없으면 입력 화면에서 즉시 신규 등록 가능** (별 페이지 안 가도 됨, 모달)

```
┌─ 발행처 ───────────────────────┐
│ [아테┃                       🔍]│
├────────────────────────────────┤
│ 🏢 ㈜아테일리           광고주   │ ← 클릭으로 선택
│    220-86-12345                │
│ 🏢 아테스튜디오          매체사  │
│    -                            │
│ ─────────────────────────────  │
│ ➕ '아테┃' 신규 거래처 등록      │ ← 클릭하면 모달
└────────────────────────────────┘
```

#### 자동 계산
- 매출금 입력 → VAT(10%), 총매출 자동
- 매입금 입력 → 동일
- VAT 수동 수정 가능 (반올림 차이 보정)
- 손익·성과급은 실시간 표시 (편집 불가)
- 성과급% = 상품구분 카테고리의 `commission_rate` 자동
  - 단, 영업이 수동 override 가능 (특수 룰)

#### 거래코드 자동 채번
- 사용자가 `담당자`와 `귀속월` 선택하면 미리보기로 `AZ260514` 표시
- 확정저장 시 같은 prefix+YYMMDD가 있으면 `-1`, `-2` 자동 부여
- 사용자가 직접 입력해도 됨 (수동 모드)

#### 실시간 검증/경고
- 매출금 < 매입금 → ⚠️ 역마진 경고 (저장은 가능)
- 사업자번호 없는 발행처 → ⚠️ 세금계산서 발행 불가 경고
- 광고종료 < 광고시작 → ❌ 저장 불가
- 동일 거래코드 존재 → ❌ 저장 불가

#### 키보드 단축키 (엑셀 사용자 친화)
- `Tab` / `Shift+Tab`: 다음/이전 필드
- `Enter`: 자동완성 후보 선택 또는 폼 저장 (Ctrl+Enter)
- `Ctrl+S`: 임시저장
- `Ctrl+Shift+S`: 확정저장
- `Esc`: 취소
- `Ctrl+D`: 복제하여 새로 만들기 (반복 거래)

#### 입력 보조
- "어제와 동일" 버튼 — 직전 입력값 자동 채움
- "이 거래처 마지막 거래 복제" — 자주 거래하는 거래처 빠른 입력
- 매입금 입력시 매체사의 마지막 수수료율 자동 적용

### 2.3 상태별 폼 동작

| 상태 | sales 역할 | accountant 역할 |
|---|---|---|
| draft (임시저장) | 모든 필드 편집 가능 | 모든 필드 편집 가능 |
| confirmed (확정) | 금액 외 편집 가능 (메모/날짜 등) | 모든 필드 편집 가능 |
| closed (완료) | **읽기 전용** | 편집 가능 |

→ 폼 상단에 현재 상태 배지 + 잠금 표시

- 우클릭 → 컨텍스트 메뉴 (복제/삭제/CSV)
- URL 파라미터로 필터 영구화 (북마크 가능)

## 8. 기술스택 결정에 필요한 정보

| 영역 | 요구사항 |
|---|---|
| **인증** | 이메일/패스워드, 옵션 2FA, 세션 8시간 |
