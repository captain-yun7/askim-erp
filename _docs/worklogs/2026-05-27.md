## 결정 사항
- **구현 형태: 웹 (Next.js 유지)** — 다중 사용자/단일 진실원천, 3법인(국내·중국·미국) 접근성, 권한 서버측 검증, 외부 연동(경리나라/네이버웍스 웹훅) 모두 웹 전제. 이미 Next.js 스택으로 출발.
- **PC 패킹 방식: PWA 채택** — Chrome/Edge 설치 버튼 1회로 바탕화면·시작메뉴 아이콘 + 주소창 없는 전용 창 + 작업표시줄 독립 아이콘 확보. Electron/Tauri는 본 프로젝트 요구사항상 불필요(용량/빌드 파이프라인 부담만 큼).
- **엑셀형 입력 UX는 그리드 컴포넌트로 해결** — AG Grid / Handsontable / Glide Data Grid 중 선택해 데스크톱 ERP 수준의 입력 속도 확보.

## 이슈 & 해결
- **이슈:** docx에서 글머리 기호가 두 번 표시됨 (`•  •  텍스트`).
  - **원인:** `add_paragraph(style="List Bullet")`의 자동 글머리 + 직접 추가한 `•` 문자가 중복.
  - **해결:** 스타일 제거 후 일반 문단에 `•/◦` 글머리만 수동으로 삽입. 들여쓰기는 `left_indent`로 처리.
- **이슈:** pandoc/python-docx 모두 미설치 상태.
  - **해결:** `pip3 install --user python-docx`로 사용자 영역 설치 (1.2.0).
