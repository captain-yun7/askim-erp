- **라이트/화이트 base 확정, 다크모드 미사용.** 디자인 레퍼런스: flex.team(구조) + Pennylane(시각). 메모 `design-renewal-direction.md` 참조.

- **전월 대비는 귀속연월 둘 다 지정될 때만 노출**(모호성 회피), 미지정 시 정적 설명 문구.
- **사이드바는 전체 메뉴 구조를 미리 노출**하되 미구현(P2 리포트·관리)은 "준비중" 비활성 처리 → 빈 화면 없이 제품 윤곽 확보.
- 현재 메뉴 3개(거래·거래처·판관비)는 P0 핵심 + P1 판관비 범위였고, 기획상 대시보드·리포트·관리가 더 있음을 재확인.

## 이슈 & 해결
- **디자인 시안과 포팅 결과 미세 불일치** → claude design 파일 재확인(최신 맞음), 포팅 중 실용적 치환 3건(번호형 페이지네이션, export 버튼, 카드 아이콘 border 박스) 시안대로 복구.
- **dev 포트 혼선(3000 vs 3300)** → `.env.local`의 `AUTH_URL`은 이미 3300. `package.json` dev 스크립트를 `next dev -p 3300`으로 정합. 다른 세션이 3300 점유 중이라 백그라운드 `npm run dev`는 EADDRINUSE(정상).
- **flex.team 제품 이미지 로그인 월** → raw HTML curl + asset URL grep으로 실제 제품 카드 이미지 추출, Pennylane 공개 스크린샷으로 시각 레퍼런스 보강.
- **대시보드 쿼리 반환 객체 `month` 키 중복** → `period`/`thisMonth`로 구조 분리.
- 미입금/미결산 알림은 `*DueDate < today AND status pending`만 집계 → 시드 데이터 예정일이 미래/공란이면 0건 표시될 수 있음(데이터 의존, 정상 동작).
